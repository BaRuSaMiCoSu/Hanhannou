# Hanhannou

酸化還元の半反応式を暗記するためのテストアプリ。

## 開き方

`index.html` をブラウザで開くだけです（外部依存なし・オフラインで動作）。
`index.html` と `questions.js` は同じフォルダに置いてください。

- **PC**: ファイルをダブルクリック
- **スマホ**: ファイルを端末に保存してブラウザで開く、または GitHub Pages を有効化して URL でアクセス

## 機能

- 出題形式：名称 → 変化 / 変化 → 名称 / 酸化剤・還元剤の判別
- 出題範囲：酸化剤のみ / 還元剤のみ / 全部（酸化剤 21 + 還元剤 22 = 全 43 問）
- 自己採点式。間違えた問題は正解するまで同一セッション内で再出題
- 進捗（残り問題数・正答率）と、終了時の結果サマリ・間違えた問題一覧

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | UI と出題エンジン |
| `questions.js` | 問題データ（`OXIDIZERS` / `REDUCERS` / `ITEMS`） |

問題を追加・修正するときは `questions.js` だけを編集します。1 件のデータは
`name`（名称）/ `eq`（半反応式）/ `change`（変化）/ `n`（価数）/ `level`（基礎・入試）/ `note`（一行解説）
を持ちます。表記ルールはファイル冒頭のコメントを参照してください。
